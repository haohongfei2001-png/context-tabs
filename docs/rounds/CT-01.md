# CT-01 — Functional Core

Status: IN_PROGRESS

## Scope

Implement the minimum useful Chrome MV3 extension without crossing into CT-02/03/05.

Required:

- toolbar action opens the Context Tabs Side Panel
- list tabs from the current Chrome window
- active-tab indication
- click row to activate tab
- close tab
- `+` creates a normal Chrome New Tab
- `AI+` creates a new active `https://chatgpt.com/` tab
- create new tabs immediately after the current tab when Chrome permits
- reconcile UI from Chrome tab events
- zero host permissions and zero content scripts
- minimal automated contract tests and CI

Explicitly deferred:

- search
- drag reorder
- dedicated pinned section
- tab-group UI
- aliases
- ChatGPT DOM interception

## Acceptance

1. `manifest.json` is valid MV3 and does not declare `chrome_url_overrides`, host permissions, or content scripts.
2. The Side Panel can be opened from the extension action.
3. Current-window tabs can be listed, activated, and closed.
4. Normal `+` and `AI+` are separate actions.
5. Chrome is the operational truth and tab events trigger reconciliation.
6. Automated tests pass in required CI.
7. Native Chrome behavior remains available when the extension is disabled.
