# CT-01 — Functional Core

Status: COMPLETE

## Scope

Implement the minimum useful Chrome MV3 extension without crossing into CT-02/03/05.

Delivered:

- toolbar action opens the Context Tabs Side Panel
- list tabs from the current Chrome window
- active-tab indication
- click row to activate tab
- close tab
- `+` creates a normal Chrome New Tab
- `AI+` creates a new active `https://chatgpt.com/` tab
- create new tabs immediately after the current tab when Chrome permits
- reconcile UI from Chrome tab events
- zero host permissions and zero content scripts
- automated contract/unit tests and required CI

Explicitly deferred:

- search
- drag reorder
- dedicated pinned section
- tab-group UI
- aliases
- ChatGPT DOM interception
